# Hardware disponible y alternativas

## Equipamiento principal

| Dispositivo | Unidades | Uso previsto |
|---|---|---|
| Meta Quest 2 | 3 | Bloque VR |
| Meta Quest 3 | 2 | VR y MR con passthrough |
| Apple Vision Pro | 2 | MR con PolySpatial |
| iPad compatible con ARKit | 1 | Bloque AR |

Coordina el acceso con el ayudante del laboratorio. El calendario combina
bloques para distribuir el uso del equipamiento.

## Teléfonos personales

Un teléfono iOS o Android compatible puede ser una alternativa en AR, pero
no es un requisito del curso. La compatibilidad y las capacidades necesarias
se verificarán para cada módulo; no todos los dispositivos ofrecen escaneo
de mallas, profundidad u oclusión equivalentes.

## HTC Vive Pro

Es una alternativa para quienes dispongan de un PC adecuado. No es el objetivo
principal de los tests ni de los builds. La guía de configuración se completará
al validar esa ruta.

## HoloLens 1

Se reserva para un módulo bonus histórico con un entorno de desarrollo propio.
Su configuración y compatibilidad siguen pendientes de validación; no se exige
para completar la ruta mínima.
