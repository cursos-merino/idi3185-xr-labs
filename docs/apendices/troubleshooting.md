# Resolución de problemas

## El módulo no tiene starter ni tests

El libro está en construcción. Las páginas marcadas como pendientes no son
actividades publicadas. Espera a que el equipo docente habilite el módulo.

## No puedo acceder al repositorio

Comprueba que estás usando la cuenta GitHub invitada y que aceptaste la
invitación a la edición. Contacta al ayudante si el acceso sigue pendiente.

## Unity muestra errores de paquetes

La matriz de versiones se fijará con M1. Cuando esté disponible, compara la
versión del editor y los paquetes con las instrucciones antes de modificarlos.
Conserva el mensaje completo y los pasos que reprodujeron el error.

## El libro no se genera

Activa el entorno virtual, instala `requirements-docs.txt` y ejecuta
`python -m mkdocs build --strict` desde la raíz del repositorio. Si falla la
instalación, verifica acceso a PyPI. Si falla el build, revisa el primer error
y los enlaces o páginas que menciona.

## Necesito ayuda con una actividad

Revisa el módulo, pregunta al ayudante y, si hace falta, abre un Issue que
incluya módulo, entorno, resultado esperado, resultado observado y error.
Solicita la solución con el template específico solo después de intentarlo.
