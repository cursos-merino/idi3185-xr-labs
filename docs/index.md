# Laboratorios de Realidad Extendida

Libro práctico de **IDI 3185 — Realidad Extendida**, Pontificia Universidad
Católica de Chile, DILAB-UC. Explora realidad virtual (VR), aumentada (AR) y
mixta (MR) mediante actividades autoguiadas de aproximadamente una hora.

!!! warning "Libro en construcción"
    Esta versión contiene la infraestructura y el índice de los 21 módulos.
    Los tutoriales, starters, tests y builds todavía no están disponibles.
    El primer módulo que se implementará y revisará será M1.

## Ruta de aprendizaje

Comienza con M0 y M1. Luego realiza las muestras V1, X1 y A1 según el
calendario sugerido. Después puedes profundizar en uno o más bloques.

Los cinco módulos obligatorios suman 50 puntos. El umbral de aprobación es
60 puntos; un electivo aprobado permite completar la ruta mínima.

Consulta [cómo usar el libro](como-usar-el-libro.md) y el
[calendario sugerido](apendices/calendario-sugerido.md).
